# PHP Notes App

A learning project built while completing the **PHP for Beginners** course by Laracasts.

The project was built from scratch with vanilla PHP to learn how the core concepts behind modern PHP applications and frameworks work.

## Features

- User registration
- Login and logout
- Session-based authentication
- Create, read, update and delete notes
- User-specific notes
- Authorization
- Form validation
- Custom routing
- Middleware
- MySQL database with PDO
- Dependency container
- Composer autoloading
- PestPHP testing

## Technologies

- PHP
- MySQL
- PDO
- Composer
- PestPHP
- HTML
- Tailwind CSS

## What I Learned

This project helped me understand how common backend concepts work under the hood, including routing, controllers, authentication, sessions, middleware, validation, dependency injection and database interactions.

## Running the Project

Install Composer dependencies:

`composer install`

Start the PHP development server:

`php -S localhost:8888 -t public`

A MySQL database is required to run the application.
